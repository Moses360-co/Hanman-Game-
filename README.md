# Hangman Game – Python

## Project Overview

The Hangman Game is a simple and interactive word-guessing game developed using Python.

In this game, players need to guess a hidden word by entering one letter at a time. Players have a limited number of attempts to find the correct word. If they guess the word correctly, they win. Otherwise, the game ends when all attempts are used.

## Project Objectives

- Develop a fun word-guessing game using Python.
- Understand Python programming fundamentals.
- Practice conditional statements and loops.
- Implement string manipulation.
- Improve logical thinking and problem-solving skills.

## Technologies Used

- Python
- Random Module
- String Operations
- Conditional Statements
- Loops
- Functions

## How to Play

1. Start the Hangman Game.
2. A random hidden word will be selected.
3. Guess one letter at a time.
4. Correct guesses reveal the letters.
5. Incorrect guesses reduce your remaining attempts.
6. Guess the complete word to win the game.
7. Run out of attempts and the game is over!

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/Moses360-co/Hangman-Game.git
```

2. Navigate to the project folder:

```bash
cd Hangman-Game
```

3. Run the Python file:

```bash
python hangman.py
```
